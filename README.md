# dsh-im-wechat

把微信（WeChat，腾讯 iLink 协议）接入 DeepSeek Harness 的 IM 桥插件。

> **状态：功能可用（M0–M4）。** 协议客户端、桥适配、图片入站与 Web 面板均已实现并通过单测；真机验收清单见 [AGENTS.md](AGENTS.md)。设计决策见 [docs/adr/](docs/adr/README.md)。

## 定位

- 两种用法：作为 `dsh-my-superagent` 的 IM 桥（协议 `my-superagent/v1`）时，核心决定发什么、本插件决定怎么呈现，主人的消息与作答回交核心；**不装核心插件、单独安装也能用**，此时插件不向任何核心注册，自己把问题提醒与长任务提醒发到微信。
- 微信侧走腾讯 iLink：扫码登录、长轮询收消息、主动发送；实现只参考腾讯官方 `openclaw-weixin` 的接口与协议定义，自写零运行时依赖客户端（[ADR-0001](docs/adr/0001-基于openclaw-weixin的零依赖微信桥.md)）。
- 两半式插件：host 半（Node，协议与桥）+ client 半（Web 设置面板）。
- 不做独立直聊：单独安装时也没有自己的对话代理，入站自由聊天不会回话（[ADR-0003](docs/adr/0003-一期只做桥不做独立直聊.md)）；图片只做入站（[ADR-0004](docs/adr/0004-图片入站与下载安全.md)）。

## 安装

```bash
dsh plugin --profile web add file:/Users/ankh/workspace/private/dsh-plugins/dsh-im-wechat
# host 半改动后重装生效：先 remove，等十几秒再 add
```

新装即生效：loader 直接载入，不用重启 `dsh web`，刷新设置页就能看到「微信」。**不装 `dsh-my-superagent` 也能这样装**，面板会显示「未接入超级助理」，插件按单独安装的模式工作。

装好后在设置页找到「微信」：点「扫码登录」，用手机微信扫面板上的二维码（扫不了就复制链接在手机微信里打开），确认后状态变成「已登录」。登录态落在 `$DSH_HOME/dsh-im-wechat/login.json`（`0600`），重启或重装后沿用，不随包发布。

## 插件特性

装不装核心插件都能用，差别只在「消息由谁转交、提醒由谁发」：

| 能力 | 单独安装 | 接入我的超级助理 |
| --- | --- | --- |
| 扫码登录、面板设置 | 支持 | 支持 |
| 问题提醒、长任务提醒 | 插件自己发 | 核心发 |
| 在微信里回复问题作答 | 支持 | 支持（经核心） |
| 主人消息转交核心、交付送微信 | 不可用 | 支持 |
| 主人图片作为附件入站 | 不可用 | 支持 |

- **登录与收发**：手机微信扫码确认即可登录；长轮询收消息、主动接口发消息，不需要公网地址和回调域名。
- **交付呈现**：核心的 Markdown 交付降级成纯文本发到微信，单条超过 1800 字按段分条（`maxText` 可配）。
- **问题提醒**：题目与选项写成文字发到微信，回复序号或文字就能作答；微信与 Web 竞答，谁先答用谁，另一边自动收起。
- **长任务提醒**：超过阈值（默认 30 分钟，面板可改）的回合结束时，推送标题、耗时与最后结论。
- **只打扰该打扰的人**：只提醒主人和根会话，子代理的提问与回合不打扰。
- **不重复提醒**：接入我的超级助理后插件自动让位，问题与长任务提醒交给核心（[ADR-0006](docs/adr/0006-问题提醒与长任务提醒归谁发.md)）。
- **正在输入**：主人的消息交给核心后、首段交付送达前，微信那头显示「正在输入」，长思考不再像石沉大海；真机行为不符预期时可用 `typingIndicator: false` 关掉（[ADR-0007](docs/adr/0007-输入状态.md)）。
- **设置面板**：设置页里完成扫码登录、开关渠道、改长任务阈值，并查看账号尾号、桥接状态、提醒来源与最近错误；中文默认，跟随宿主浅色/深色主题。

## 使用

以下是接入核心时的收发行为；单独安装时只有提醒与作答（见上一节）。

- 主人在微信里发消息 → 插件把它交给核心，命令解析、主人判定都由核心做（单独安装时没有这一步，入站消息不会回话）；核心受理后到首段交付送达前，微信显示「正在输入」。
- 核心的交付 → 插件拍平成纯文本并发到微信；超过 1800 字按段分条。
- 没有交互卡：核心的问题与选项由插件写成文字，主人回复序号或文字即可作答。
- 面板上的两个开关：**接入微信（收消息）** 控制插件是否工作；**接入我的超级助理** 决定提醒由谁发——接入时由核心发，关掉后插件自己发问题提醒（与 Web 竞答）和长任务提醒（超过阈值，默认 30 分钟）到微信（[ADR-0006](docs/adr/0006-问题提醒与长任务提醒归谁发.md)）。
- 主人在微信里发的图片会作为附件交给核心（需要核心声明 `owner-images`）。

## 配置

profile 的 `cordis.patch.yml` 里按 loader id 叠加配置（改完重启 `dsh web`）：

```yaml
- id: dsh-im-wechat
  config:
    longTaskThresholdMinutes: 45   # 长任务提醒阈值（分钟），默认 30，范围 1–1440
    maxText: 1800                  # 单条消息字符上限，默认 1800
    typingIndicator: true          # 「正在输入」状态，默认开（ADR-0007）
```

面板上的「接入微信（收消息）」「接入我的超级助理」与长任务阈值会落到
`$DSH_HOME/dsh-im-wechat/config.json`（`0600`），**优先于** profile 配置，卸载重装后沿用。

## 目录

- `src/host/ilink/` — iLink 协议客户端（类型、HTTP、登录、长轮询、发送、媒体）
- `src/host/state/` — 登录态、长轮询游标与 `context_token` 的本机持久化
- `src/host/superagent/` — `my-superagent/v1` 桥适配与呈现降级
- `src/host/runtime.ts`、`src/host/panel-rpc.ts` — 运行期装配与面板 RPC
- `src/client/` — Web 设置面板
- `src/shared/` — 跨上下文的纯函数（版本、二维码编码器）
- `docs/adr/` — 架构决策记录
