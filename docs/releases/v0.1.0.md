## 主要变更

首个版本：把微信（iLink）接进 DeepSeek Harness，既能作为 `dsh-my-superagent` 的 IM 桥，也能不装核心单独使用。

- **扫码登录即用**：设置页里点「扫码登录」，手机微信扫一下确认即可，不需要公网地址、回调域名或第三方服务；登录态落在 `$DSH_HOME/.dsh-im-wechat/login.json`（`0600`），重启与重装后沿用
- **收发文字与图片**：长轮询收消息，主动接口发消息；文字与图片都支持，单条超过 1800 字按段分条
- **Markdown 原样透传**：微信客户端原生渲染 Markdown，表格、代码块、标题、列表、链接都按原样显示；图片标记、`#####`、中文斜体与删除线标记会被剔除（微信侧不渲染）
- **独立模式直连会话**：不装 `dsh-my-superagent` 时，插件在 `$DSH_HOME/dsh-im-wechat` 自动建一个「微信会话」工作区，首条消息在那里建会话并持续复用；回合正在跑时可以选插话或排队；面板里用下拉框换工作区
- **微信图片进会话**：主人发来的图片会下载成会话附件（png/jpeg/webp/gif），模型能直接看图；模型不支持图片时自动去掉图片、用同一个请求号重发文字，不会丢文字
- **present 的图片回传微信**：独立模式下模型在会话里 `present` 的本地图片会直接发到主人微信（只发图片，单张 ≤ 10 MiB、一次 ≤ 10 张）
- **提醒**：问题与长任务提醒；超过阈值（默认 30 分钟，可改）的回合结束时推送标题、耗时与结论，失败立刻提醒且不受开关影响；只提醒主人在根会话，接入核心后自动让位，不重复打扰
- **出站快捷命令**：`dsh-wechat-send`（命令行）与 `/wechat`（斜杠命令）把文字或图片发到主人微信，模型在任意会话里一条命令即可；收件人恒为扫码登录的主人
- **设置面板**：扫码登录、渠道开关、工作区选择、长任务阈值，并查看账号尾号、绑定会话、提醒来源与最近错误；中文默认，跟随宿主浅色/深色主题

## 安装

```bash
# 正式版（npm）
dsh plugin --profile web add dsh-im-wechat@0.1.0

# 同一版本的 GitHub Release 附件
dsh plugin --profile web add https://github.com/xbzbing/dsh-im-wechat/releases/download/v0.1.0/dsh-im-wechat-0.1.0.tgz
```

装好后刷新设置页，在「微信」里扫码登录。host 半有改动时先 `dsh plugin --profile web remove dsh-im-wechat`，等十几秒再装回去。

## English

First release: brings WeChat (iLink) into DeepSeek Harness — usable as an IM bridge for `dsh-my-superagent`, or standalone without the core.

- **Scan-and-go login**: open the WeChat panel and scan the QR code with the phone; no public URL, callback domain, or third-party service. The session lives in `$DSH_HOME/.dsh-im-wechat/login.json` (`0600`) and survives restarts and reinstalls
- **Text and images both ways**: long-poll inbound, active API outbound; long text splits into parts over 1800 characters
- **Native Markdown passthrough**: tables, code blocks, headings, lists and links render as-is in the WeChat client; image markers, `#####`, Chinese italics and strikethrough markers are stripped
- **Standalone direct sessions**: without `dsh-my-superagent`, the plugin creates a "微信会话" workspace under `$DSH_HOME/dsh-im-wechat`, creates one session there on the first message and keeps using it; while a turn runs, choose steer or queue; the panel's dropdown switches workspaces
- **Images from WeChat**: images the owner sends are downloaded into the session as attachments (png/jpeg/webp/gif), so the model can see them; a model without image support gets the text resent under the same request id instead of losing it
- **Presented images forwarded**: in standalone mode, images the model `present`s in the bound session go straight to the owner's WeChat (images only, ≤ 10 MiB each, ≤ 10 per call)
- **Reminders**: question and long-task reminders; turns past the threshold (30 minutes by default) report title, duration and conclusion, and failures notify immediately regardless of the switch; only the owner and root session are notified, and reminders step aside once the core is attached
- **Outbound shortcuts**: `dsh-wechat-send` and `/wechat` deliver text or images to the owner's WeChat from any session; the recipient is always the owner who scanned in
- **Settings panel**: scan-to-login, channel toggles, workspace picker, long-task threshold, plus account tail, bound session, reminder source and recent errors; Chinese first, follows the host's light/dark theme

```bash
# Stable (npm)
dsh plugin --profile web add dsh-im-wechat@0.1.0

# The same version as a GitHub Release asset
dsh plugin --profile web add https://github.com/xbzbing/dsh-im-wechat/releases/download/v0.1.0/dsh-im-wechat-0.1.0.tgz
```

Refresh the settings page after installing and scan the QR code in the WeChat panel. After a host-half change, remove the plugin, wait a few seconds, then add it back.
