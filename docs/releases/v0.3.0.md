## 主要变更

- **文件可以直接发了**：微信里发 PDF、Office 文档、压缩包不再是「附件目录里找不到」。插件按与图片同一道边界下载解密，再交给会话的附件暂存，模型拿到只读副本、用文件工具自己打开。单条消息 ≤ 32 MiB、最多 3 个；超限、解密失败、上传失败都会说清是哪一份没进去，文字与图片照常送达（[ADR-0028](https://github.com/xbzbing/dsh-im-wechat/blob/master/docs/adr/0028-独立模式的文件入站.md)）。
- **微信里能管会话了**：`/help`、`/new`、`/sessions`、`/send`、`/trace`、`/stop`、`/status` 七个命令——开新会话、翻会话列表、往指定会话发一句话、盯住某个会话的每轮结果，都不用回电脑前。`/send` 与 `/trace` 用一次 `/sessions` 的快照编号寻址，序号不会因为列表变动而串会话（[ADR-0027](https://github.com/xbzbing/dsh-im-wechat/blob/master/docs/adr/0027-独立模式的微信文字命令.md)）。
- **引用回复能指认到具体附件**：同一会话里发过多份文件时，引用其中一份问「这个文件…」，插件会把「引用的是哪一份」还原成一行 `[引用：文件 …]` 标头交给模型，不再只能按最近那份猜。索引只留最近 200 条消息的摘要，插件重启前一直有效（[ADR-0029](https://github.com/xbzbing/dsh-im-wechat/blob/master/docs/adr/0029-独立模式的引用还原.md)）。
- **会话的模型与推理等级可以在面板里选**：provider → model → effort 三级下拉，不选就跟随 DSH 默认；选中的值每轮幂等钉住，主人在 Web 端换过模型也不会被悄悄改回去（[ADR-0025](https://github.com/xbzbing/dsh-im-wechat/blob/master/docs/adr/0025-独立模式会话的模型.md)、[ADR-0026](https://github.com/xbzbing/dsh-im-wechat/blob/master/docs/adr/0026-独立模式会话的推理等级.md)）。
- **面板的反馈与状态补齐**：保存有明确提示，账号显示完整值（悬停可见），会话标题显示全名；面板 RPC 契约升到 7，两半版本不一致时会给出诊断。
- **修复**：插话时图片被丢弃仍会回执说明；连续插话不再重复提示；目标会话在跑且走排队时，跟踪不再丢轮次；命令先于「这条是不是在回答待答问题」处理，`/help` 不会被当成某个问题的答案吞掉。
- **内部**：独立模式的装配收进 `direct-stack`，`limits` 同时管标题长度；新增 ADR-0027、0028、0029 三篇决策记录。

## Highlights

- **You can send files now**: PDFs, Office documents and archives no longer end up as "no file in the attachment directory". The plugin downloads and decrypts them behind the same boundary as images, hands the bytes to the host's attachment staging, and the model gets a verbatim read-only copy to open with its file tools. Up to 32 MiB and 3 files per message; oversize, decryption or upload failures name the file that did not make it, while text and images are still delivered ([ADR-0028](https://github.com/xbzbing/dsh-im-wechat/blob/master/docs/adr/0028-独立模式的文件入站.md)).
- **Manage sessions from WeChat**: `/help`, `/new`, `/sessions`, `/send`, `/trace`, `/stop` and `/status` — start a new session, page through the session list, send a line into a specific session, and follow any session turn by turn, without walking back to the desktop. `/send` and `/trace` address sessions by the snapshot numbers from `/sessions`, so ids do not shift under you ([ADR-0027](https://github.com/xbzbing/dsh-im-wechat/blob/master/docs/adr/0027-独立模式的微信文字命令.md)).
- **Quote replies name the attachment**: when several files have been sent in one session, quoting one of them and asking "this file…" now carries a `[引用：文件 …]` header into the model, instead of letting it guess the most recent one. The index keeps the last 200 message summaries and never expires them before a plugin restart ([ADR-0029](https://github.com/xbzbing/dsh-im-wechat/blob/master/docs/adr/0029-独立模式的引用还原.md)).
- **Model and reasoning effort are selectable in the panel**: a provider → model → effort cascade that follows the DSH default when unset; the choice is pinned idempotently every turn, so picking a model in the Web UI is never silently reverted ([ADR-0025](https://github.com/xbzbing/dsh-im-wechat/blob/master/docs/adr/0025-独立模式会话的模型.md), [ADR-0026](https://github.com/xbzbing/dsh-im-wechat/blob/master/docs/adr/0026-独立模式会话的推理等级.md)).
- **Panel feedback and status**: saving reports its outcome, the account shows in full on hover, session titles are shown in full, and the panel RPC contract moves to 7 with a diagnostic when the two halves disagree.
- **Fixes**: dropped images during a steer are reported instead of vanishing; repeated steers stop repeating the same notice; a queued turn no longer loses the followed turn; commands are handled before "is this an answer to a pending question", so `/help` is not swallowed as an answer.
- **Internal**: standalone wiring moved into `direct-stack`, `limits` also bounds titles, and ADR-0027/0028/0029 record the new decisions.
