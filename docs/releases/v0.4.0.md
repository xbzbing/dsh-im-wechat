## 主要变更

- **接入核心后，文件也能进来了**：核心声明 `owner-files` 时，微信里发来的文件会随消息交给核心（最多 3 个、单个 8 MiB、单条合计 16 MiB）。以前这条路径上的文件会被静默丢掉——只发文件不写字的消息在微信里连回执都没有。现在核心收得到，超限或失败的文件也会在微信里明说没收到。
- **引用能对上被引用的那一条**：入站草稿带上了这条消息自己的平台 `message_id`，与用户引用它时带回来的 `replyTo` 是同一个值。核心据此把自己记住的「哪条消息带了什么」对上号，不会再把「这个文件」猜成最近的一份。
- **扫码登录改成弹层**：登录不再挤在连接区右列，改为居中弹窗。二维码是弹层里唯一有底色的元素，Esc、点遮罩、底部「取消」都能关；登录进行中关闭即取消这次登录，不会在后台继续轮询二维码。
- **不再显示二维码的原文链接**：只留「复制链接」「打开链接」两个按钮。二维码画不出来时给一句说明，而不是把链接铺成一列 monospace 文本。
- **修复「提醒来源」文案**：未接入核心时曾显示「由超级助理发送」。原因是判断绑在了「自有提醒是否生效」上（未登录、停机时它是假），现在只按接入开关判断，未接入就是「由本插件发送」，连接卡与运行概览共用同一处逻辑。
- **内部**：面板新增通用 `Dialog` 原语（焦点进卡片、Tab 循环、关闭后焦点还给触发按钮、打开时锁页面滚动）；发布流程文档补上 `src/shared/version.ts` 这一处版本号——它由单测钉住与 `package.json` 一致，漏改会在门禁上红。

## English

- **Files now reach the core**: when the core declares `owner-files`, files sent in WeChat are handed over with the message (up to 3 files, 8 MiB each, 16 MiB per message). Previously files on this path were dropped silently — a message with only a file produced no reply at all. Oversized or failed files are now reported back in WeChat by name.
- **Quotes resolve to the message that was quoted**: the inbound draft now carries the message's own platform `message_id`, the same value the platform hands back as `replyTo`. The core can match it against the record of what each message contained instead of guessing at the most recent attachment.
- **QR sign-in is a modal**: signing in no longer takes a column of the connection panel; it opens a centered dialog. The QR code is the only surface with a background colour, and Esc, backdrop click and the Cancel button all close it. Closing while the flow is running cancels the sign-in instead of polling the QR code in the background.
- **The raw QR link is gone**: only "Copy link" and "Open link" remain. When the QR code cannot be drawn, a single sentence explains it instead of dumping the URL as monospace text.
- **Fixed the "reminder source" label**: without the core it used to read "sent by My Superagent". The check was tied to whether the plugin's own reminders were currently active (false when signed out or stopped), not to the integration switch. It now follows the switch alone, and the connection card and the runtime overview share one helper.
- **Internal**: new generic `Dialog` primitive in the panel (focus into the card, Tab cycling, focus restored to the trigger, page scroll locked); the release docs now also list `src/shared/version.ts`, whose version constant is pinned to `package.json` by a unit test.
