## 主要变更

- **插件改名为「微信机器人」**：插件页与设置页统一显示「微信机器人」/「WeChat Bot」。插件页读 `locale/<lang>.json` 的 `meta.title`、设置页读面板字典的 `panel.title`，两处各有一半时会出现两个名字，现由单测钉住它们一致。
- **面板直接显示完整账号**：面板「账号」不再显示尾号、也不再依赖悬停看全文，直接显示完整账号（`status.account`）；旧宿主不返回 `account` 时退回尾号。日志、`/status` 等对外文本仍用尾号（`accountTail`），完整账号不铺到这些地方；README 与 AGENTS 的账号显示口径同步。
- **内部**：`Fact` 去掉不再使用的 `hint` 参数与对应样式，`ui.ts` 的 Tooltip 包装一并删除；面板 RPC 契约版本未变（没有端点或返回结构调整）。

## English

- **Renamed to “WeChat Bot”**: the plugin page and the settings page now both show「微信机器人」/ “WeChat Bot”. The plugin page reads `meta.title` from `locale/<lang>.json` while the settings page reads `panel.title` from the panel dictionary, so changing only one half used to leave two different names; a unit test now pins them together.
- **The panel shows the full account**: the “Account” row no longer shows the tail and no longer needs a hover to reveal the whole value — it renders the full account (`status.account`) directly, falling back to the tail when an older host omits `account`. Logs and `/status` keep using the tail (`accountTail`); the full account is not spread into those places. README and AGENTS now describe this split.
- **Internal**: `Fact` drops the now-unused `hint` prop and its style, and the Tooltip wrapper in `ui.ts` is gone; the panel RPC contract version is unchanged (no endpoint or response shape change).
